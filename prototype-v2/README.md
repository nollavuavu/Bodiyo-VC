# Lift – prototype v2

Gym-app prototype, local-first. There are no accounts and no backend. Nothing is sent anywhere: no network calls, no fonts and no CDNs, and the Lucide icons are vendored. Open `index.html` directly; it works from `file://`.
The user-facing name is **Lift** (`APP_NAME` in data.js). Internal identifiers (the `carlsen2.` storage prefix, `CARLSEN_*` globals) are never shown.

Build: see "Build stamp" at the end (written by the last `sh tools/build.sh` before reporting).

## Features
1. **Start a workout** from the next split day, any day of the plan or a community split, or as an empty workout (`#/train`).
2. **Edit mid-workout**: add, remove (with undo), swap ("Just today" or "Update plan") and reorder exercises. Add or remove sets. The rest timer starts at 2:30 and has −15 / +15 buttons. Sets are validated inline.
3. **Weekly tracker** (`#/week`): a hard set is a ticked set at RIR ≤ 3, and a blank RIR counts as the target RIR. A secondary muscle counts ½ set. Sessions per muscle are counted only where the muscle is primary. Weeks run Monday 00:00 local time and are DST-safe.
4. **Reminders**: friendly, never blocking, with one Why? each.
5. **Split builder and custom exercises**: saving is never blocked. The coaching notes are suggestions only.
6. **Community splits**: 5 samples, labelled "Sample data".
7. **Adaptive next-session suggestion** (T9 double progression, T14 last-set RIR): +1 rep inside the range; +2.5 kg (or +1 kg under 10 kg) at the top of the range or when the last set was easier than the target; hold the load when sets end harder than the target; +1 rep for bodyweight.
8. **EN / VI language switch** on You (see i18n).

Importer rules:
- It reads numbered topics only and skips `**Research notes (not shown in app):**` lines and curator or QA notes.
- It drops retracted and do-not-use papers and strips "(see Topic N)".
- `Carlsen` in the evidence text becomes `Lift`.
- Citations keep authors, year, title, journal, volume, DOI, PubMed id, `[tags]` and the study detail, verbatim.
- `check-evidence-leaks.js` fails the build if a research-note sentence, an excluded paper (Barbalho, Graham, Cleather) or a PMID named only in research notes reaches evidence.json.

Exercise `evidenceNote`s (20, exercises.json round 2) are shown because `exerciseNotes: true`. Evidence text and evidence notes stay English (`lang="en"`). Vance's `../i18n/evidence.vi.json` is a draft pending Hoang's term review and is **not** loaded.

## Security (security.md, Laurent)
- All user-entered and imported text goes through one audited `esc()` (app.js), and every `T()` output placed in HTML goes through `TE()` / `esc()`.
- Lookups use own properties only, so prototype-named routes (`#/exercise/__proto__` …) render a stub.
- Stored shapes are validated, and bad data is dropped instead of crashing.
- CSP meta: `default-src 'none'`, `script-src 'self'`, `style-src 'self'`, `connect-src 'self'`. Bar widths use `data-w` and `applyWidths()`.
- `safeUrl` allows https only, links use `rel="noopener noreferrer"`, and PubMed links require digits.
- Selectors use `CSS.escape`. `LS.del` is wrapped in try. History is capped at 1000. The test hook `window.__carlsen` exists only when `window.__LIFT_TEST__ === true`.

## i18n
- Strings live in `/workspace/carlsen/i18n/en.json` (canonical) and `vi.json`. vi.json is **Vance's**; the build never writes it, and its values stay replaceable.
- Keys are flat and namespaced, with `{placeholders}`, `.one` / `.other` plurals, and `Intl` dates and numbers (en-GB / vi-VN). There is no string concatenation.
- See `../i18n/KEYS.md`.
- `?lang=en|vi|pseudo` overrides the saved choice. The You switch saves `carlsen2.lang` and reloads.
- The pseudo-locale is test-only: bracketed text, accents and +40 % length.
