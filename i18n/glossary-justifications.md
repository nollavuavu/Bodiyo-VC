# Justifications for the glossary terms that are not approved yet

Regenerated from glossary-vi.json (glossary-vi.md (draft 2, 29 Oct 2026: evidence pass + Hoang decisions 19:01/19:04 + approved-terms list 19:15)). 84 of 100 terms still need Hoang's decision; 16 are approved and left out: RPE → RPE (thang nỗ lực), failure / to failure → "ngưỡng thất bại"; to failure = "đến ngưỡng thất bại" (e.g. "tập đến ngưỡng thất bại"), hard set → "set nỗ lực" (no plural form: "3 set nỗ lực", "các set nỗ lực"), effort → "nỗ lực" ("mức nỗ lực", "mức nỗ lực cảm nhận" for perceived exertion), close to failure / ends hard → "cận ngưỡng thất bại"; comparatives use "gần … hơn" ("gần ngưỡng thất bại hơn", "càng gần ngưỡng thất bại"), volume (sets) → "khối lượng tạ" (meaning number of hard sets); "total volume" = "tổng khối lượng tạ", total load lifted / tonnage → "tổng khối lượng nâng", progressive overload → "quá tải lũy tiến", double progression → "lũy tiến kép", glossed "lũy tiến kép (tăng rep trước, rồi tăng tạ)" on first use, custom exercise → "bài tập" ("Tạo bài tập", "Bài tập mới", "Xóa bài tập"); the "Custom" tag stays "Tự tạo", mechanical tension → "sức căng cơ học"; plain "sức căng" for "tension", lengthened partials → "rep nửa biên độ giãn" ("bắp chân nửa biên độ giãn" etc.), resistance profile → "sơ yếu kháng lực", primary muscle (agonist) → "cơ chủ vận", Abs → Cơ bụng (muscle label and sentences), cable → cáp (no "puly"); pulley height is written "cáp đặt thấp / cáp đặt cao / cáp đặt ngang ngực".

Each line gives the proposed wording and why. ⚠ marks the ones I am least sure about. Terms tagged *new in evidence pass* come from the evidence (Why?) translation.

## Effort and failure

- **RIR (reps in reserve)** → RIR (số rep còn dư); in sentences: "còn dư 1–2 rep". Abbreviation-first ORDER approved by Hoang (19:04); the gloss "số rep còn dư" is still my proposal.
- **reps in reserve (spelled out, column hint)** → "số rep còn dư". Plain explanation of the abbreviation; same gloss as "RIR (số rep còn dư)" (gloss not yet approved).
- **effective reps** → "rep hiệu quả". Literal and already used in VN fitness content.

## Load, reps, sets, progression

- **set** → set. Universal in VN gyms ("3 set 12 rep"); "hiệp" sounds like a textbook or a boxing round. ⚠ Confirm you prefer "set" over "hiệp" app-wide.
- **rep / reps** → rep. Same as set; "lần lặp" is only used in formal writing.
- **rep range** → "khoảng rep" (e.g. "khoảng 6–12 rep"). Short and clear.
- **weight / load** → "mức tạ", "tạ". What lifters actually say ("lên tạ", "giữ tạ").
- **1RM** → 1RM (mức tạ tối đa cho 1 rep). Abbreviation-first ORDER approved by Hoang (19:04); the gloss is still my proposal. Mostly in research copy.
- **load step / weight step** → "bước tăng tạ". Plain.
- **Hold (suggestion) / Next (suggestion)** → "Giữ nguyên" / "Lần tới". Matches the suggestion card.
- **prescription (sets × reps · RIR · rest)** → "Thông số của bạn" (section label); never "đơn/chỉ định". "Prescription" sounds medical in Vietnamese. ⚠
- **bodyweight (load)** → "trọng lượng cơ thể"; in tight cells: "Không tạ". "Bodyweight × 10" → "Không tạ × 10" fits the cell. ⚠ "tạ người" is common slang, check.

## Rest, timing, frequency

- **rest / rest between sets** → "nghỉ", "nghỉ giữa các set". Everyday.
- **rest timer** → "đồng hồ nghỉ". Short, clear; "bộ đếm giờ nghỉ" is longer.
- **frequency (per muscle)** → "tần suất" → in UI "số buổi mỗi tuần cho mỗi nhóm cơ". "Tần suất" alone is abstract; spell it out where space allows.
- **session / workout** → "buổi tập". One word for both avoids confusion.
- **deload / deload week** → "tuần deload (tuần giảm tải)". Many VN lifters say "deload"; gloss makes it clear it's an easy week, not stopping.
- **diminishing returns** → "lợi ích giảm dần". Plain; only in Why? copy.
- **dose-response (more sets help, each adds a bit less)** → "càng nhiều set càng có lợi, nhưng mỗi set thêm có lợi ít hơn". Explain, don't name.

## Programming and splits

- **split (training split)** → "lịch tập"; "split" kept in names. VN lifters say both; "lịch tập" is what a beginner understands.
- **plan** → "kế hoạch" / "lịch tập của bạn". "Plan" tab = "Kế hoạch".
- **Full Body** → "Toàn thân (Full Body)". Both forms are used.
- **Upper / Lower** → "Thân trên / Thân dưới". Literal and natural.
- **Push / Pull / Legs (PPL)** → "PPL (Đẩy / Kéo / Chân)". Abbreviation-first ORDER approved by Hoang (19:04); the gloss is still my proposal. "PPL" is widely known.
- **Hybrid (UL + PPL)** → "UL + PPL (Kết hợp)". Rewritten for the abbreviation-first rule (was "Kết hợp (UL + PPL)"). ⚠ "UL + PPL (Kết hợp)" vs "Kết hợp UL + PPL" (no brackets) – which reads better as a split name?
- **Bro split** → "Bro split – mỗi ngày một nhóm cơ". Known slang in VN gyms.
- **superset** → superset – "tập 2 bài liền nhau, không nghỉ giữa". Established loanword; no VN equivalent in common use.
- **compound exercise** → "bài đa khớp (compound)". Established VN term.
- **isolation exercise** → "bài đơn khớp (isolation)". Established VN term.
- **community splits** → "lịch tập cộng đồng". Plain.
- **sample data** → "dữ liệu mẫu". Plain.
- **swap (exercise) / best match** → "đổi bài" / "phù hợp nhất". Plain.
- **coaching notes** → "lời khuyên". Friendlier than "ghi chú huấn luyện". ⚠
- **cues** → "lưu ý kỹ thuật". "Cue" has no everyday VN equivalent.

## Muscle length and resistance profile

- **lengthened position / stretch position** → "vị trí giãn cơ" ("cơ dài nhất"). "Giãn cơ" is everyday; avoids "vị trí kéo dài".
- **shortened position / squeeze** → "vị trí co cơ" / "đoạn siết cơ". "Siết cơ" is common gym talk for the squeeze.
- **full range of motion (ROM)** → "ROM (biên độ) đầy đủ"; later "ROM đầy đủ" / "hết biên độ". Abbreviation-first ORDER approved by Hoang (19:04); the gloss "biên độ" is still my proposal.
- **Hardest near the stretch / in the middle / near the squeeze** → "Nặng nhất ở đoạn giãn cơ" / "Nặng nhất ở giữa biên độ" / "Nặng nhất ở đoạn siết cơ". Mirrors the three English labels exactly.
- **range of motion** → "biên độ chuyển động". Established.
- **negative / eccentric (lowering phase)** → "pha hạ tạ (negative)". "Negative" is used in VN gyms; "ly tâm" is academic.
- **dead hang** → "treo thả lỏng". Descriptive.
- **hinge (movement)** → "gập hông". Plain.

## Muscles (app's 14 + extras)

- **secondary (helper) muscle** → "cơ hỗ trợ". Standard; "½ set" stays.
- **Chest** → Ngực. Standard.
- **Front delts / Side delts / Rear delts** → Vai trước / Vai giữa / Vai sau. Standard VN gym names. ⚠ "vai giữa" vs "vai bên"
- **Lats** → Lưng xô. Standard gym term.
- **Upper back** → Lưng trên. Plain.
- **Spinal erectors** → Cơ dựng sống (lưng dưới). Anatomical + plain gloss.
- **Biceps / Triceps** → Tay trước / Tay sau. What VN lifters say ("bắp tay trước/sau" also fine).
- **Forearms** → Cẳng tay. Standard.
- **Quads / Hamstrings** → Đùi trước / Đùi sau. Standard.
- **Glutes** → Mông. Standard.
- **Adductors** → Đùi trong. Plain ("cơ khép" is anatomical).
- **Calves** → Bắp chân. Standard.

## Equipment and app UI words

- **barbell / dumbbell** → tạ đòn / tạ đơn. Standard.
- **machine / Smith machine** → máy / máy Smith. Standard.
- **EZ bar** → đòn EZ. Standard.
- **bench / pad** → ghế / đệm. Standard.
- **Full gym / Dumbbells / Bodyweight (equipment setup)** → Phòng gym đầy đủ / Tạ đơn / Không dụng cụ (tạ người). Describes the setup, not the load.
- **Why?** → Tại sao?. Short chip; "Vì sao?" also fine. ⚠ "Tại sao?" vs "Vì sao?"
- **evidence strength** → "mức độ bằng chứng". Plain.
- **research note** → "ghi chú nghiên cứu". Plain.
- **tick (a set)** → "đánh dấu xong". Matches the checkmark.

## New in evidence pass (Why? sheets and citation details)

- **muscle growth / hypertrophy** → "tăng cơ"; "phát triển" for a single muscle ("cơ đùi trước phát triển"). Everyday words; avoids the academic "phì đại cơ". New in evidence pass. ⚠ "tăng cơ" vs "phát triển cơ"
- **evidence grades Strong / Moderate / Limited / Weak / Theoretical** → "Mạnh" / "Trung bình" / "Hạn chế" / "Yếu" / "Lý thuyết". Short labels that match the English grades one to one. New in evidence pass.
- **meta-analysis / systematic review / narrative review** → "phân tích tổng hợp" / "tổng quan hệ thống" / "bài tổng quan tường thuật". Standard Vietnamese research terms. New in evidence pass.
- **meta-regression / network meta-analysis** → "phân tích hồi quy tổng hợp" / "phân tích tổng hợp mạng lưới". Follows the meta-analysis term. New in evidence pass. ⚠
- **trial / randomised trial / crossover / within-subject** → "thử nghiệm" / "thử nghiệm ngẫu nhiên" / "thiết kế bắt chéo" / "so sánh trên cùng người". Plain; "so sánh trên cùng người" explains one-arm/one-leg designs. New in evidence pass.
- **trained / untrained (participants)** → "người đã có kinh nghiệm tập" / "người chưa tập". Plain, not "đã qua huấn luyện". New in evidence pass.
- **muscle thickness** → "độ dày cơ". Literal and clear. New in evidence pass.
- **CSA (cross-sectional area)** → "CSA (tiết diện cơ)" on first use, then "tiết diện cơ". Abbreviation-first rule. New in evidence pass.
- **lean mass / fat-free mass** → "khối nạc" / "khối không mỡ". Standard body-composition terms. New in evidence pass.
- **volume load** → "tổng khối lượng nâng" (proposal). Close to Hoang's tonnage term as he asked; volume load (sets × reps × load) is the same quantity as tonnage, so one term. New in evidence pass. ⚠ Proposal: same words as tonnage; alternative "tổng khối lượng nâng (volume load)" on first use.
- **velocity loss / bar velocity** → "mức giảm tốc độ" / "tốc độ đòn". Descriptive. New in evidence pass. ⚠
- **autoregulation / autoregulated** → "tự điều chỉnh (mức tạ)". Describes what happens: load set by how the day feels. New in evidence pass. ⚠
- **resistance curve** → "đường kháng lực". Matches "sơ yếu kháng lực". New in evidence pass. ⚠
- **partial ROM / initial (lengthened) ROM** → "ROM một phần" / "ROM một phần ở đoạn đầu (đoạn giãn)". Abbreviation-first rule. New in evidence pass.
- **eccentric / isometric** → "pha hạ tạ (eccentric)" / "tĩnh" (e.g. "lực tĩnh"). Keeps the gym word "pha hạ tạ"; "ly tâm" is academic. New in evidence pass.
- **vastus lateralis / rectus femoris / vastus intermedius** → "cơ đùi ngoài (vastus lateralis)" / "cơ thẳng đùi (rectus femoris)" / "cơ đùi giữa (vastus intermedius)". Plain name + Latin on first use. New in evidence pass.
- **gastrocnemius / soleus / gluteus maximus** → "cơ bụng chân" / "cơ dép" / "cơ mông lớn". Standard anatomy names. New in evidence pass.
- **elbow flexors / knee extensors** → "cơ gập khuỷu" / "cơ duỗi gối". Literal and clear. New in evidence pass.
- **proximal / distal (region)** → "phần gần" / "phần xa". Standard anatomy wording. New in evidence pass. ⚠
- **not significant / effect size** → "không có ý nghĩa (thống kê)" / "hệ số ảnh hưởng". Standard Vietnamese statistics terms. New in evidence pass.
- **online ahead of print** → "Đăng trực tuyến trước khi in.". Standard. New in evidence pass.
